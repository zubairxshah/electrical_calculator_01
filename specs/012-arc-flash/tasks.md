# Tasks: Arc Flash Calculator

**Input**: Design documents from `/specs/012-arc-flash/`
**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md), [research.md](./research.md), [data-model.md](./data-model.md), [contracts/calculation-api.md](./contracts/calculation-api.md), [quickstart.md](./quickstart.md)

**Tests**: REQUIRED. Spec FR-023 and Constitution Principle V (TDD, non-negotiable for calculation logic) both require them. Test tasks in each story come first and MUST fail before the matching implementation.

**Organization**: Tasks are grouped by user story (spec US1–US5) so each story can be built and tested on its own.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on incomplete tasks)
- **[Story]**: US1–US5 from spec.md
- Paths are relative to the repo root `D:\prompteng\elec_calc\`

## Conventions every task must follow (from research R11 / project memory)

- Internal units are **SI** (V, kA, mm, ms, J/cm²). Convert only at UI/PDF edges. 1 cal/cm² = 4.184 J/cm². 1 in = 25.4 mm.
- Arithmetic: **native `number`**, not mathjs (plan D2 / research R5).
- Store handlers read state via `useArcFlashStore.getState()` (stale-closure rule). Never use `useCallback([store])`.
- Numeric `<Input>`s use focus/blur local string state. Never bind a number directly.
- Components in `components/arc-flash/` are presentational (props in, callbacks out). Only `ArcFlashTool.tsx` and `ArcFlashHistorySidebar.tsx` import the store.
- Alert styling: error `bg-destructive/10 border-destructive/50` + `AlertCircle`; warning `bg-yellow-50 border-yellow-200` + `AlertTriangle`; info `bg-blue-50 border-blue-200` + `Info`.
- Reference implementation for patterns: `app/conduit-fill/ConduitFillTool.tsx`, `stores/useConduitFillStore.ts`, `lib/pdfGenerator.conduitFill.ts`, `components/conduit-fill/*`.
